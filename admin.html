पहली बार? एक बार सेट करना होगा

यह टोकन सिर्फ़ इसी फ़ोन में सेव रहेगा। किसी को न भेजें।

टोकन कैसे बनाएँ?
  1. github.com/settings/personal-access-tokens/new खोलें
  2. Repository access → Only select repositories → sabzi चुनें
  3. Permissions → Repository permissions → Contents → Read and write
  4. Expiration में No expiration या 1 साल चुनें
  5. Generate token दबाएँ, टोकन कॉपी करके ऊपर डालें

यह टोकन सिर्फ़ इसी एक repository को बदल सकता है, और कुछ नहीं।
